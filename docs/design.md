# แนวทางดีไซน์ UI — Mangosteen Campus

> ต้นฉบับ wireframe (design canvas): https://claude.ai/artifact/QB2y8Qod4AtkfVVFEoWxaZ
> ไฟล์นี้สรุปสิ่งที่อยู่ใน canvas ให้ session ใหม่ใช้ได้โดยไม่ต้องเปิดลิงก์ — ถ้าขัดกัน ให้ยึด canvas แล้วอัปเดตไฟล์นี้

## หลักการ
- โทนสะอาด เรียบ เน้นใช้งานง่าย (อ้างอิงสไตล์ Mango CMU) ไม่ใช้การ์ดลอย/เงา ใช้เส้นคั่นบาง ๆ แบ่งเนื้อหา
- จุดเด่นของแบรนด์คือ **ตราดอก 6 กลีบ** (กลีบเลี้ยงมังคุด) ใช้เป็นโลโก้ใน sidebar และเป็นลายน้ำจางมุมขวาบนของทุกหน้า
- ข้อความทั้งหมดเป็น translation key (ค่า default = ไทย) — ดู i18n ใน `CLAUDE.md`

## ตัวอักษร
- หัวข้อ/ตัวเลข: **Taviraj** (serif) น้ำหนัก 500–700
- เนื้อความ/UI: **IBM Plex Sans Thai** น้ำหนัก 400–600
- ตอน implement ควรพิจารณา self-host (`@fontsource`) แทนโหลดจาก Google Fonts — ยังไม่ตัดสินใจ

## โครงหน้า (Dashboard)
- Sidebar ซ้ายกว้าง 264px (พื้น `plum-800`): โลโก้ → เมนูตาม role → โปรไฟล์ + ออกจากระบบ
- เนื้อหาหลัก: คำทักทาย + ปุ่มสลับ TH/EN มุมขวาบน → ตัวเลขสำคัญ 3 ตัวคั่นด้วยเส้นตั้ง → สองคอลัมน์ (รายการหลัก 1.6 : รายการรอง 1)

| Role | เมนู sidebar | ตัวเลขสำคัญ | คอลัมน์หลัก / รอง |
|---|---|---|---|
| Admin | แดชบอร์ด · จัดการผู้ใช้ · สนับสนุนระบบ · สลับมุมมอง · Audit Log | ผู้สอน · ผู้เรียน · วิชาที่เปิดสอน | กิจกรรมล่าสุด / ทางลัด |
| Teacher | แดชบอร์ด · รายวิชาของฉัน | วิชาที่สอน · ผู้เรียน · งานรอตรวจ | งานที่รอตรวจ / รายวิชาของฉัน |
| Student | แดชบอร์ด · รายวิชาของฉัน · ประกาศ | วิชาที่ลงทะเบียน · งานสัปดาห์นี้ · ประกาศยังไม่อ่าน | งานที่ต้องทำเร็ว ๆ นี้ / ประกาศล่าสุด |

## รายการหน้าจอ และสถานะ wireframe

| หน้า | สถานะ |
|---|---|
| Dashboard ทั้ง 3 role (desktop) | มีใน canvas |
| Login / สมัครสมาชิก / ตั้งรหัสผ่าน / สถานะอีเมล (desktop) | มีใน canvas — **ผู้ใช้อนุมัติแล้ว** (ลิงก์ "ลืมรหัสผ่าน" อยู่ใต้ช่องรหัสผ่าน) |
| Login + Student dashboard (มือถือ) | มีใน canvas — **ผู้ใช้อนุมัติแล้ว** (รวมกระดิ่งแจ้งเตือนบน top bar มือถือ) |
| กระดิ่งแจ้งเตือนบน dashboard desktop | อนุมัติแนวคิดแล้ว แต่ยังไม่ได้เพิ่มลงใน wireframe desktop (ตำแหน่งที่เสนอ: ข้างปุ่ม TH/EN) |
| กระดิ่งแจ้งเตือน, กรอกรหัสเข้าเรียน (Student) | ยังไม่มี — เสนอตอนทำฟีเจอร์ enrollment/notification |
| จัดการภาคเรียน (Admin), สร้างรายวิชา (Teacher) | ยังไม่มี — เสนอตอนทำฟีเจอร์ academics |
| Dashboard มือถือของ Admin / Teacher | ยังไม่มี — ใช้แพตเทิร์นเดียวกับ Student มือถือ |
